Scheduler decision log

Data structure. The ready queue is a binary min-heap written from scratch in this file. Each entry is an array [criterion, tie-breakers…, pid], so the smallest entry is always the most urgent process.

Greedy strategy. At every scheduling point the CPU takes the best local choice, the heap minimum, without looking ahead. The algorithms differ only in the key: FCFS uses arrival time, SJF uses burst time, SRTF uses remaining time, Priority uses the priority number.

Preemption. A running process executes until it finishes or the next process arrives. If it is unfinished it goes back into the heap, so the heap re-decides on every arrival.

Complexity. There are at most 2n scheduling events and each heap operation costs O(log n), so the total is O(n log n) time and O(n) space.

Trade-offs. SRTF gives the lowest average waiting time. Priority scheduling favours important work but can starve low-priority processes; aging is the usual fix.
